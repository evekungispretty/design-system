### Shape & spacing

Every size uses `radius/pill` (999px) — buttons are always fully rounded, never a fixed corner radius. Icon-to-label gap is a constant 4px across all variants and sizes.

| Size | Height | Padding (V / H) |
| --- | --- | --- |
| Default (Primary, Secondary, Outline Orange) | 42px | 12px / 16px |
| Default (Tertiary, Tertiary Dark BG) | — | 8px / 12px |
| Default (Text, Text Dark BG) | — | 4px / 16px |
| Big (Primary only) | 60px | 8px / 32px |

### Elevation & motion

Every button carries a resting shadow (`0 6px 18px #1A1C29`). On hover, the button lifts (`translateY(-10px)`, 150ms ease-out); on press it returns flush (`translateY(0)`, 100ms). Only `transform`, `box-shadow`, and `background-color` transition — never `all`. Under `prefers-reduced-motion: reduce`, the lift is dropped and only the color change remains.
