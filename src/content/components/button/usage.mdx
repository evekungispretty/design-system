Button triggers a single, immediate action — submitting a form, starting checkout, confirming a dialog. Seven visual styles cover a hierarchy of emphasis, from a single page-level Primary action down to low-emphasis Text and Tertiary actions.

### Choosing a variant

- **Primary** — the one main action on a screen. Solid orange fill.
- **Secondary** — a supporting action next to a Primary, or the main action when nothing needs full Primary emphasis. White fill with a border that appears on hover/active.
- **Tertiary** — low-emphasis action, no border, transparent until hovered.
- **Text** — the lowest-emphasis action, tighter vertical padding, reads almost like a link.
- **Outline Orange** — an orange-bordered alternative to Secondary, for contexts that want brand color without full Primary weight.
- **Text Dark BG / Tertiary Dark BG** — the Text and Tertiary treatments, recolored for use on dark or saturated backgrounds (footer, hero panels).

### Sizing

Default (42px tall) is the standard size for nearly all contexts. Big (60px tall) exists for high-emphasis moments — hero CTAs, checkout confirmation — and today is only defined in Figma for the Primary variant.
