Pill is a static, non-interactive label — for tagging a course by category, showing a status word, or surfacing a bit of metadata inline with other content. In the source file it's used for course-category chips (phonics, vocabulary, comprehension) and similar short tags.

Pill is not a button and not a form control. If you need something clickable, use [Button](/components/button) instead; if you need a selectable segmented control, use Tab / Tab Group.

Six colors are available. Five are flat, high-contrast fills meant to sit on a plain background; White is the one variant with a border and subtle inner shadow, meant for use on colored or busy surfaces where a flat fill wouldn't stand out.
