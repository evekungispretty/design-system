### Semantics

The card is a `figure`: the person's details are its `figcaption` and the quote is a `blockquote`. That gives screen readers a proper attribution relationship.

### Avatar

The avatar is decorative — the name is already in the text — so the image has empty `alt` text and the fallback initial is hidden from assistive tech.

### Link

The link text ">> 點我看推薦影片" describes where it goes; keep a description like this rather than a bare "click here". The link is focusable with a 2px `border/focus` ring.

### Contrast

The link `#447CA2` on white is about 4.5:1 — a pass, with little room to spare. Quote and name are `#1A1A1A` on white.
