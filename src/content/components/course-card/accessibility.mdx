### Semantics

The card is an `article` and the title is a heading — pick `h2`, `h3` or `h4` so the heading order on the page stays correct. The thumbnail area is content-free by default; if you pass an image that carries meaning, give it descriptive `alt` text, and leave `alt=""` if it's purely decorative.

### Not interactive

The card has no focus or hover state. If it links somewhere, put the link on the title (or wrap the card) in your page so there's one clear, focusable target.

### Contrast

Title `#1A1A1A` and description `#4A4A4A` both pass on either surface. The description is set very small — step -2, about 11 to 13px — so it's worth checking it stays readable at your smallest breakpoint. White pill text passes on both red and purple fills.
