List Item is one row in a vertical list of links. In the source file it lists podcast episodes that open in another site — the row text wraps, and a small external-link icon at the right edge says the link leaves.

Stack several to make a list; each row carries its own bottom divider. Figma draws only the **External** variant of the row (with the icon). The library section is also titled for internal links, but no internal variant is drawn, so internal rows here are simply the same row without the icon.
