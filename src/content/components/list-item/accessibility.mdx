### Semantics

List Item renders a native `a`. Put several inside a `ul`/`li` (or a `nav`) so a screen reader announces the list and its length.

### External links

`external` opens the link in a new tab with `rel="noopener noreferrer"`. The icon is decorative, so a visually hidden "(opens in a new tab)" is added after the text — the icon alone would tell screen reader users nothing.

### Contrast

`#1A1A1A` on white is well above 4.5:1. The row's divider is a decorative separator, not a control boundary.
